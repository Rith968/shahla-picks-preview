# مختارات شهلاء — معاينة

معاينة لمتجر مختارات شهلاء (ووردبريس + ووكومرس) تعمل داخل المتصفح عبر WordPress Playground.

- **الموقع:** https://playground.wordpress.net/?blueprint-url=https://raw.githubusercontent.com/Rith968/shahla-picks-preview/main/blueprint.json
- **لوحة التحكم (حساب مدير المتجر):** https://playground.wordpress.net/?blueprint-url=https://raw.githubusercontent.com/Rith968/shahla-picks-preview/main/blueprint-admin.json

أول فتح ياخذ دقيقة إلى دقيقتين (ينزّل حوالي 120 ميغا). كل شخص يفتح الرابط تنبني له نسخة مستقلة في متصفحه، وأي تعديل فيها ما يأثر على غيره.

هذه نسخة معاينة فقط وليست الموقع النهائي.
